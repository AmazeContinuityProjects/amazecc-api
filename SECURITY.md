# Security Policy

## Supported Versions

This API uses a rolling release. The latest commit on the `main` branch is always supported.

## Reporting a Vulnerability

**Please do not report security vulnerabilities in public issues, pull requests or discussions.**

Report them privately through GitHub's private vulnerability reporting:
**Security tab → Report a vulnerability** on this repository
(https://github.com/AmazeContinuityProjects/amazecc-api/security/advisories/new).

Include what you found, the affected route(s), and steps to reproduce. We'll
acknowledge the report, keep you updated while we fix it, and credit you in the
advisory unless you'd rather stay anonymous.
